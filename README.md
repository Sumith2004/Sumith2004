### 📄 [Productive RAG](https://github.com/Sumith2004/productive-RAG)

**Ask questions across PDFs and Word documents.**

A document Q&A application that parses text, tables, and images, creates searchable embeddings, and generates answers from retrieved context. Includes persistent chatbot sessions.

`Python` · `Streamlit` · `Chroma` · `Sentence Transformers` · `Groq`

### 💬 [Roastify Me](https://github.com/Sumith2004/NLP_Roster)

**An interactive experiment in sentiment-aware responses.**

Generates roasts and compliments using sentiment analysis, with text-to-speech playback and session history.

`Python` · `Streamlit` · `TextBlob` · `gTTS`

**Explore a machine learning workflow through an interactive app.**

An educational prediction project combining notebook experimentation, input preprocessing, and a Streamlit interface for exploring model outputs.

`Python` · `pandas` · `Jupyter` · `Streamlit`
